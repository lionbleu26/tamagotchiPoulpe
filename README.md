# 🐙 Tamagotchi Poulpe

Un jeu **Tamagotchi style rétro** où tu dois t'occuper d'un adorable poulpe virtuel ! Nourris-le, donne-lui à boire et fais-le dormir pour le garder en vie et heureux.

🔗 **[Jouer à la démo en ligne](https://tamagotchi-poulpe.vercel.app)** _(remplace par ton URL Vercel)_

---

## 🎮 Fonctionnalités

- **3 jauges à gérer** :
  - 🍔 **Faim** (nourris ton poulpe avec le bouton "Nourrir")
  - 💧 **Soif** (donne-lui à boire avec "Boire")
  - 😴 **Énergie** (fais-le dormir avec "Dormir")
- **Système de game over** si une jauge atteint 0.

---

## 🛠 Technologies utilisées

- **HTML5** / **CSS3**
- **JavaScript vanilla** (ES6) – Pas de framework !
- Hébergé sur **[Vercel](https://vercel.com/)** (déploiement continu).
